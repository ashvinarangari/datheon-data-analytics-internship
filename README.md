## Highlights

- **Task 1:** Cleaned the dataset to retain 9,994 records.
  Analysed monthly sales, customer segments, category purchase
  volumes, and discount patterns. Every observed discount
  level of 30% or more recorded negative aggregate profit.
  This association does not establish causation.

- **Task 2:** Created a two-page Power BI report with sales,
  profit, orders, and margin KPI cards; interactive slicers;
  a monthly sales trend; a category treemap; a product
  profitability matrix; and a discount-versus-margin chart.

## How to View the Work

- Open each project folder and read its README.
- Open the Jupyter notebooks on GitHub to view saved charts,
  tables, and findings.
- Download the `.pbix` file and open it in Power BI Desktop
  on Windows to explore the interactive report.
- To run a notebook locally, keep its CSV in the same folder
  and install the libraries listed in the project README.
